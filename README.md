# Open World Prototype - 회사 빌딩

지하 5층 ~ 지상 17층짜리 회사 빌딩 하나를 무대로 삼은 2D 탑다운 프로토타입입니다.
Phaser 3(클라이언트) + Vercel 서버리스 함수(NPC 대화 API, `api/npc/[npcId]/chat.js`)로 구성되어 있습니다.

## 실행 방법 (로컬)

로컬 개발 서버는 [Vercel CLI](https://vercel.com/docs/cli)의 `vercel dev`로 실행합니다.
Vite 프론트와 `api/` 아래 서버리스 함수를 함께 띄워줍니다.

### 1. NPC 대화용 Claude API 키 설정 (선택)

NPC와 대화하려면 Anthropic API 키가 필요합니다. 키가 없어도 이동/탐험/엘리베이터는 정상 동작하고,
NPC에게 말을 걸면 "대답이 없다"는 안내만 표시됩니다.

```bash
cp .env.example .env.local
# .env.local 파일을 열어 ANTHROPIC_API_KEY 값을 채워주세요
```

### 2. 설치 및 실행

```bash
npm install
npm run dev
```

`http://localhost:3000` (vercel dev 기본 포트)으로 접속합니다.

## 배포 (Vercel)

이 저장소를 Vercel 프로젝트로 그대로 import하면 됩니다 (Framework: Vite 자동 감지).
배포 전에 Vercel 프로젝트 설정 → Environment Variables에 `ANTHROPIC_API_KEY`를 등록해주세요
(`.env`/`.env.local` 파일은 배포에 포함되지 않습니다).

> NPC 대화 기록은 서버 메모리가 아니라 클라이언트가 들고 있다가 매 요청에 함께 보냅니다.
> 서버리스 함수는 인스턴스가 매번 새로 뜰 수 있어 상태를 유지하지 않기 때문입니다.

## 조작법

- 이동: 방향키 또는 WASD
- `E`: 가까운 NPC와 대화 / 엘리베이터 탑승
- 대화창에서 `Enter`로 전송, `Esc`로 닫기
- 엘리베이터 패널에서 층 버튼 클릭, `Esc`로 닫기

## 출근 타임어택 모드

- **제한시간 3분** 안에 최대한 점수를 모으세요. 시간이 끝나면 결과 화면이 뜨고 최고 기록이 저장됩니다(localStorage).
- 커피를 짧은 시간(2.2초) 안에 연속으로 먹으면 **콤보**가 붙어 점수 배수가 최대 x5까지 올라갑니다.
- 가끔 **잔소리 부장(추격자)**이 나타나 플레이어를 쫓아옵니다. 잡히면 스트레스 게이지가 오르고 콤보가 끊기며, 게이지가 가득 차면 "번아웃"으로 즉시 게임 종료됩니다. 커피를 먹으면 스트레스가 조금 줄어듭니다.
- 커피 획득/피격 시 파티클과 효과음(WebAudio로 즉석 생성, 별도 파일 없음)이 재생됩니다.
- 결과 화면에서 "다시 도전" 버튼(또는 `Enter`)으로 즉시 재시작할 수 있습니다.

## 건물 구조

지상 17층 ~ 지하 5층(B5), 엘리베이터로 층 이동 (매 층 같은 위치에 배치).
층마다 테마에 맞는 바닥/오브젝트가 고정 시드로 배치되어, 다시 방문해도 같은 배치를 보여줍니다.
층에 흩어진 커피를 모아 점수 획득.

| 층 | 테마 | 오브젝트 |
|---|---|---|
| B5 ~ B3 | 주차장 | 기둥, 주차된 차 |
| B2 | 구내식당 | 식당 테이블 |
| B1 | 서버실 | 서버랙 |
| 1F | 로비 | 화분, 안내 데스크 |
| 2F | 카페 | 원형 카페 테이블 |
| 3F ~ 14F, 16F | 사무실 | 책상, 화분 |
| 15F | 휴게공간 | 소파, 화분 |
| 17F | 대표실 | 대표 책상, 화분 |

## NPC (Claude API 기반 대화)

| NPC | 위치 | 캐릭터 |
|---|---|---|
| 경비원 아저씨 | B3 (주차장) | 지하 주차장을 순찰하는 경비원 |
| 구내식당 아주머니 | B2 (구내식당) | 배식을 담당하는 정겨운 아주머니 |
| 안내데스크 직원 | 1F (로비) | 방문객을 안내하는 리셉션 직원 |
| 바리스타 | 2F (카페) | 사내 카페에서 커피를 내리는 바리스타 |
| 김 팀장 | 9F | 회의와 마감에 시달리는 중간관리자 |
| 대표님 비서 | 17F (대표실) | 대표이사실 앞을 지키는 비서 |

각 NPC는 `lib/npcs.js`에 정의된 페르소나로 Claude API를 호출해 실시간으로 대답합니다.
대화 기록은 NPC별로 클라이언트가 들고 있다가 매 요청에 함께 전송하며, 세계관을 벗어난 질문은
캐릭터에 맞게 넘기도록 프롬프트에 규칙을 넣어두었습니다.
