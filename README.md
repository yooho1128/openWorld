# Open World Prototype - 회사 빌딩

지하 5층 ~ 지상 17층짜리 회사 빌딩 하나를 무대로 삼은 2D 탑다운 프로토타입입니다.
Phaser 3(클라이언트) + Express(NPC 대화 프록시 서버)로 구성되어 있습니다.

## 실행 방법

### 1. NPC 대화용 Claude API 키 설정 (선택)

NPC와 대화하려면 Anthropic API 키가 필요합니다. 키가 없어도 이동/탐험/엘리베이터는 정상 동작하고,
NPC에게 말을 걸면 "대답이 없다"는 안내만 표시됩니다.

```bash
cp server/.env.example server/.env
# server/.env 파일을 열어 ANTHROPIC_API_KEY 값을 채워주세요
```

### 2. 설치 및 실행

```bash
npm install
npm run dev
```

`npm run dev`는 Vite 클라이언트(5173)와 NPC 프록시 서버(3001)를 동시에 실행합니다.
브라우저에서 `http://localhost:5173` 접속.

## 조작법

- 이동: 방향키 또는 WASD
- `E`: 가까운 NPC와 대화 / 엘리베이터 탑승
- 대화창에서 `Enter`로 전송, `Esc`로 닫기
- 엘리베이터 패널에서 층 버튼 클릭, `Esc`로 닫기

## 건물 구조

지상 17층 ~ 지하 5층(B5), 엘리베이터로 층 이동 (매 층 같은 위치에 배치).
층마다 테마에 맞는 바닥/오브젝트가 고정 시드로 배치되어, 다시 방문해도 같은 배치를 보여줍니다.
층에 흩어진 커피를 모아 점수 획득.

| 층 | 테마 | 오브젝트 |
|---|---|---|
| B5 ~ B3 | 주차장 | 기둥, 주차된 차 |
| B2 | 구내식당 | 식당 테이블 |
| B1 | 서버실 | 서버랙 |
| 1F | 로비 | 화분, 안내 데스크 |
| 2F | 카페 | 원형 카페 테이블 |
| 3F ~ 14F, 16F | 사무실 | 책상, 화분 |
| 15F | 휴게공간 | 소파, 화분 |
| 17F | 대표실 | 대표 책상, 화분 |

## NPC (Claude API 기반 대화)

| NPC | 위치 | 캐릭터 |
|---|---|---|
| 경비원 아저씨 | B3 (주차장) | 지하 주차장을 순찰하는 경비원 |
| 안내데스크 직원 | 1F (로비) | 방문객을 안내하는 리셉션 직원 |
| 김 팀장 | 9F | 회의와 마감에 시달리는 중간관리자 |
| 대표님 비서 | 17F (대표실) | 대표이사실 앞을 지키는 비서 |

각 NPC는 서버(`server/npcs.js`)에 정의된 페르소나로 Claude API를 호출해 실시간으로 대답합니다.
대화 기록은 NPC별로 서버 메모리에 유지되며(서버 재시작 시 초기화), 세계관을 벗어난 질문은
캐릭터에 맞게 넘기도록 프롬프트에 규칙을 넣어두었습니다.
