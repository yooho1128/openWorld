# 출근런

"쿠키런" 스타일의 세로 스크롤 회피 게임입니다. 대문을 나서는 출근길에서 장애물을 피하고
커피를 모아, 모은 커피로 상점에서 장비를 사서 다음 스테이지에 도전하는 구조입니다.
Phaser 3(클라이언트) + Vercel 서버리스 함수(AI 인사고과 `api/review.js`, 랭킹 `api/leaderboard.js`)로
구성되어 있습니다. PC/모바일 웹 모두 지원합니다.

## 게임 구조

1. **인트로**: 스테이지에 처음 들어가면 대문을 나서는 짧은 오프닝(탭하면 스킵)이 나옵니다. "다시 도전"으로
   재시작할 때는 생략됩니다.
2. **스테이지 선택**: 스테이지를 클리어해야 다음 스테이지가 열립니다. (인턴 → 대리 → 과장 → 부장)
   단순히 빨라지기만 하는 게 아니라 **스테이지마다 새로운 장애물 유형이 추가**됩니다 — 대리부터
   점프해야 피하는 장애물, 과장부터 숙여야 피하는 장애물이 섞입니다.
3. **러닝(회피)**: 캐릭터가 3개 레인 중 하나에 있고, 화면은 계속 위로 스크롤됩니다(좌우 벽면에는
   스테이지별로 색이 다른 패럴랙스 빌딩 배경이 흐릅니다). 좌우로 레인을 옮겨 장애물을 피하고,
   전신 장애물은 점프/숙이기로 피하세요. 목표 거리에 도달하면 스테이지 클리어, 목숨을 모두 잃으면
   중도 낙오입니다.
4. **상점**: 러닝 중 모은 커피는 스테이지 종료 시 정산되어 누적됩니다(localStorage 저장). 이 커피로
   상점에서 장비를 구매하면 이후 모든 러닝에 영구 적용됩니다.
5. **결과 화면**: 스테이지가 끝나면 이동 거리/커피/충돌 횟수/시도 횟수와 함께, **"김 팀장"이 AI로
   즉석 작성한 인사고과 한마디**가 표시됩니다. 스테이지를 처음 클리어하면 오락실 랭킹에 이름과
   시도 횟수가 등록됩니다.
6. **명예의 전당**: 스테이지별로 몇 번 만에 클리어했는지 순위표를 볼 수 있습니다 (모두에게 공유되는
   글로벌 랭킹 — 아래 "랭킹 서버 설정" 참고).

## 조작법

- 레인 이동: 방향키 ←/→, A/D, 또는 화면 좌/우 탭
- 점프(전신 장애물 회피): ↑, Space, 또는 화면 우하단 버튼
- 숙이기(전신 장애물 회피): ↓, S, 또는 화면 좌하단 버튼

## 도파민 포인트

- 장애물/커피가 멀리서 작게 나타났다가 다가올수록 커지는 원근감 연출
- 장애물을 5개 연속 피할 때마다 스트릭 보너스 커피 지급
- 커피 텀블러/스프링 구두 등 장비 효과로 런마다 체감이 크게 달라짐

## 장비 (상점)

| 장비 | 효과 | 가격 |
|---|---|---|
| 사원증 목걸이 | 목숨 +1 | 60 |
| 편한 운동화 | 레인 이동이 훨씬 빨라짐 | 90 |
| 커피 텀블러 | 획득 커피 +50% | 70 |
| 접이식 우산 | 시작 시 무적 시간 대폭 연장 | 80 |
| 노이즈캔슬링 이어폰 | 커피 자동 흡수 범위 크게 증가 | 130 |
| 무릎 보호대 | 점프/숙이기 타이밍이 더 널널해짐 | 90 |
| 스프링 구두 | 런당 1회, 점프/숙이기를 놓쳐도 자동 회피 | 160 |

한 번 구매하면 영구 소유되며 항상 적용됩니다.

## AI 활용: 인사고과 코멘트

스테이지가 끝나면 이동 거리·모은 커피·충돌 횟수·클리어 여부를 `api/review.js`로 보내
Claude(Haiku 4.5)가 "김 팀장" 페르소나로 짧은 인사고과 코멘트를 즉석 생성합니다. 매번 다른
멘트가 나오도록 실제 플레이 수치에 근거해서만 작성하게 프롬프트를 제한해뒀습니다.

## 실행 방법 (로컬)

로컬 개발 서버는 [Vercel CLI](https://vercel.com/docs/cli)의 `vercel dev`로 실행합니다.
Vite 프론트와 `api/` 아래 서버리스 함수를 함께 띄워줍니다.

### 1. AI 인사고과용 Claude API 키 설정 (선택)

키가 없어도 게임 플레이(러닝/상점/스테이지 진행/랭킹 조회)는 전부 정상 동작하고, 결과 화면의
인사고과 코멘트만 안내 문구로 대체됩니다.

```bash
cp .env.example .env.local
# .env.local 파일을 열어 ANTHROPIC_API_KEY 값을 채워주세요
```

### 2. 설치 및 실행

```bash
npm install
npm run dev
```

`http://localhost:3000` (vercel dev 기본 포트)으로 접속합니다.

## 배포 (Vercel)

이 저장소를 Vercel 프로젝트로 그대로 import하면 됩니다 (Framework: Vite 자동 감지).
배포 전에 Vercel 프로젝트 설정 → Environment Variables에 `ANTHROPIC_API_KEY`를 등록해주세요.

### 랭킹 서버 설정 (Neon Postgres)

`api/leaderboard.js`는 [`@neondatabase/serverless`](https://www.npmjs.com/package/@neondatabase/serverless)로
모두가 공유하는 글로벌 랭킹을 Postgres 테이블(`leaderboard`, 최초 요청 시 자동 생성)에 저장합니다.
DB 연동 없이는 랭킹 조회/등록이 "랭킹 서버 준비 안됨"으로 표시될 뿐 게임 자체는 정상 동작합니다.
랭킹을 켜려면:

1. Vercel 대시보드 → 해당 프로젝트 → **Storage** 탭에서 **Neon** Postgres를 추가(또는 이미 만든
   Neon DB를 연결)합니다.
2. 연결하면 `DATABASE_URL`(또는 `POSTGRES_URL`) 환경변수가 자동으로 프로젝트에 주입됩니다 —
   코드가 둘 중 있는 값을 그대로 사용하므로 별도 수정은 필요 없습니다.
3. 재배포하면 랭킹이 활성화됩니다 (테이블은 첫 조회/등록 시 자동으로 만들어집니다).
