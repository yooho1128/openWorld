# Open World Prototype

Phaser 3 + Vite로 만든 2D 탑다운 오픈월드 프로토타입입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

## 조작법

- 이동: 방향키 또는 WASD
- 목표: 맵에 흩어진 코인을 모아 점수를 올리세요.

## 현재 구현된 기능

- 4000x4000 크기의 오픈월드 맵 (타일 배경)
- 플레이어 이동 + 카메라 추적(부드러운 follow)
- 나무/바위 정적 충돌 오브젝트
- 코인 수집 및 점수 UI
- 우측 상단 미니맵 (전체 맵 개요)
