# 출근런

"쿠키런" 스타일의 세로 스크롤 회피 게임입니다. 출근길에 장애물을 피하고 커피를 모아,
모은 커피로 상점에서 장비를 사서 다음 스테이지에 도전하는 구조입니다.
Phaser 3(클라이언트) + Vercel 서버리스 함수(스테이지 결과에 대한 AI 인사고과 코멘트, `api/review.js`)로 구성되어 있습니다.

## 게임 구조

1. **스테이지 선택**: 스테이지를 클리어해야 다음 스테이지가 열립니다. (인턴 → 대리 → 과장 → 부장)
2. **러닝(회피)**: 캐릭터가 3개 레인 중 하나에 있고, 화면은 계속 위로 스크롤됩니다. 좌우로 레인을 옮겨
   장애물(박스/서류더미/캐비닛)을 피하고 커피를 모으세요. 목표 거리에 도달하면 스테이지 클리어,
   목숨을 모두 잃으면 중도 낙오입니다. 시간이 지날수록 스크롤 속도가 빨라집니다.
3. **상점**: 러닝 중 모은 커피는 스테이지 종료 시 정산되어 누적됩니다(localStorage 저장). 이 커피로
   상점에서 장비를 구매하면 이후 모든 러닝에 영구 적용됩니다.
4. **결과 화면**: 스테이지가 끝나면 이동 거리/커피/충돌 횟수와 함께, **"김 팀장"이 AI로 즉석 작성한
   인사고과 한마디**가 표시됩니다.

## 조작법

- 레인 이동: 방향키 ←/→ 또는 A/D

## 장비 (상점)

| 장비 | 효과 | 가격 |
|---|---|---|
| 사원증 목걸이 | 목숨 +1 | 50 |
| 편한 운동화 | 레인 이동 속도 증가 | 80 |
| 커피 텀블러 | 획득 커피 +20% | 60 |
| 접이식 우산 | 스테이지 시작 시 무적 시간 연장 | 70 |
| 노이즈캔슬링 이어폰 | 커피 자동 흡수 범위 증가 | 120 |

한 번 구매하면 영구 소유되며 항상 적용됩니다.

## AI 활용: 인사고과 코멘트

스테이지가 끝나면 이동 거리·모은 커피·충돌 횟수·클리어 여부를 `api/review.js`로 보내
Claude(Haiku 4.5)가 "김 팀장" 페르소나로 짧은 인사고과 코멘트를 즉석 생성합니다. 매번 다른
멘트가 나오도록 실제 플레이 수치에 근거해서만 작성하게 프롬프트를 제한해뒀습니다.

## 실행 방법 (로컬)

로컬 개발 서버는 [Vercel CLI](https://vercel.com/docs/cli)의 `vercel dev`로 실행합니다.
Vite 프론트와 `api/` 아래 서버리스 함수를 함께 띄워줍니다.

### 1. AI 인사고과용 Claude API 키 설정 (선택)

키가 없어도 게임 플레이(러닝/상점/스테이지 진행)는 전부 정상 동작하고, 결과 화면의 인사고과
코멘트만 "팀장님이 자리를 비우셨는지 대답이 없다..." 같은 안내로 대체됩니다.

```bash
cp .env.example .env.local
# .env.local 파일을 열어 ANTHROPIC_API_KEY 값을 채워주세요
```

### 2. 설치 및 실행

```bash
npm install
npm run dev
```

`http://localhost:3000` (vercel dev 기본 포트)으로 접속합니다.

## 배포 (Vercel)

이 저장소를 Vercel 프로젝트로 그대로 import하면 됩니다 (Framework: Vite 자동 감지).
배포 전에 Vercel 프로젝트 설정 → Environment Variables에 `ANTHROPIC_API_KEY`를 등록해주세요
(`.env`/`.env.local` 파일은 배포에 포함되지 않습니다).
